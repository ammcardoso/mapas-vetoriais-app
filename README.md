# SIG-Web: Regiões Administrativas de Londrina / PR

Aplicação web desenvolvida em **Next.js** e **React Leaflet** para visualização e consulta de dados geográficos vetoriais (GeoJSON) das regiões administrativas do município de Londrina, Paraná.

## 🚀 Funcionalidades

* **Visualização Vetorial por Polígonos**: Exibição interativa das 5 zonas urbanas de Londrina (Norte, Central, Sul, Leste e Oeste).
* **Estilização Dinâmica**: Cada região possui uma cor personalizada representando sua zona no mapa.
